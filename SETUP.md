# Профильный README — как выложить

Репозиторий-визитка должен называться **ровно как твой ник** — `Oneyann` — и быть **публичным**.
Только тогда GitHub показывает его README на странице профиля.

## 1. Создать репозиторий

На GitHub: **New repository** → имя `Oneyann` → Public → **Create repository**.
Галочку «Add a README file» можно не ставить: файл уже готов.

## 2. Запушить эти файлы

```powershell
cd C:\Users\User\Desktop\profile-readme
git init
git add .
git commit -m "profile readme"
git branch -M main
git remote add origin https://github.com/Oneyann/Oneyann.git
git push -u origin main
```

Открыть `https://github.com/Oneyann` — README уже на месте.

## 3. Включить карточку языков и статистики

1. В репозитории → вкладка **Actions** → «I understand my workflows, go ahead and enable them».
2. Слева выбрать **Profile stats** → **Run workflow** → **Run workflow**.
3. Через 1–2 минуты появится ветка **`output-stats`** с файлами `day.svg` и `night.svg`.
4. GitHub кеширует картинки примерно на 5 минут. Если карточка всё ещё старая — добавь в конце URL `?v=2`.

Дальше workflow сам пересобирает карточку раз в сутки и при каждом пуше в `main`.

Карточку рисует `scripts/gen-stats.mjs` — обычный Node 20 без зависимостей, данные берёт из
GitHub GraphQL API: байты по языкам во всех публичных репозиториях (форки не считаются), число
репозиториев, звёзды и контрибуции за последний год.

Визуал — пиксель-арт: сакура-бонсай (низкий изогнутый ствол, плоские ярусы кроны, горшок) с
летящими лепестками и пейзажем с двумя слоями гор и снежными вершинами (днём солнце, ночью луна).
Анимация — SMIL внутри SVG, работает в `<img>`; свои 5×7 глифы вместо системного шрифта
(`scripts/pixel-font.mjs`), сегментированные полосы языков. При системной настройке «уменьшить
движение» лепестки скрываются. Размер карточки — 800×340, в README стоит `width="800"`.

Настройки лежат в `conf/profile-stats.json`: размер карточки и пикселя, число языков, форма кроны,
количество лепестков, подписи и палитра. Дневной и ночной варианты настраиваются отдельно.

Локально пересобрать карточку можно так:

```powershell
$env:GITHUB_TOKEN = gh auth token
$env:GITHUB_REPOSITORY_OWNER = "Oneyann"
node scripts/gen-stats.mjs
```

Результат появится в `profile-stats/` (в git не попадает, папка в `.gitignore`).

## Если что-то не отрисовалось

| Симптом | Причина | Что делать |
| :--- | :--- | :--- |
| В `preview.html` часть картинок пустая, а на GitHub они видны | твой провайдер/DPI режет домен сервиса, а на GitHub картинки идут через прокси GitHub (camo) | ничего не делать, проверить уже на github.com |
| Карточка не появилась | workflow не запускался или упал | Actions → Profile stats → смотреть лог; проверить, что появилась ветка `output-stats` |
| README не виден в профиле | репозиторий назван иначе или приватный | переименовать в `Oneyann`, сделать public |

## Про `preview.html`

Это локальный предпросмотр в оформлении GitHub: открой файл в браузере.
Внутри лежит копия README, поэтому после правок в `README.md` обнови и её.

Для самого профиля нужны `README.md`, папка `.github` и `conf`. Если не хочешь держать
служебные файлы в публичном репозитории — удали `SETUP.md` и `preview.html` перед пушем.
